# Creative Studios

## AEC Collaboration Platform

Creative Studios is an integrated Architecture, Engineering and Construction workspace for managing projects, technical design information, drawings, BOQ, procurement, construction activities, documents, RFIs, approvals and project reporting.

## Current Release Status

The Vercel workspace is being maintained as the primary web interface, with Streamlit providing the operational workspace. Both interfaces are designed around the same project and database architecture.

The current UI release includes the shared Creative Studios navigation, responsive workspace shell, and the Vercel-style palette for Reports, Architecture and Tasks.
